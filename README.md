# Ping_pong

'''
**Игра пинг-понг** - игра для 2 игроков
Данная игра это **простое и понятное** в использовании приложение.
Игра нацелена на проведение время с оппонентом и оттачивании навыков

**Интерфейс**:
1. Ракетки - управляются при помощи _ws или стрелок(up down)_ в зависимости от расположения (**_левая и правая соответственно_**)
2. Мяч - передвигается _автоматически_, отталкивается от верхней и нижней стены и ракеток. **_Цель_** - недопустить касания мяча со своей стенкой

**Плюсы данного приложения**:
1. Простота управления
2. При желании можно поменять модельки мяча и ракеток
3. Возможность настройки некоторых игровых правил (скорость движения мяча/ракеток)

**Минусы данного приложения**:
1. возможность играть только 2 людям и только с одного устройства
2. при желании как то изменить приложение необзодимо вникнуть в код данного приложения
'''
